A responsive frontend clone of the Zomato landing page built using HTML, CSS, and JavaScript. This project recreates the modern user interface of Zomato, including the hero section, navigation bar, search area, and interactive design elements.

🚀 Features
Responsive design for desktop and mobile devices
Full-screen hero section with background image
Modern navigation bar
Location and restaurant search UI
Clean and attractive user interface
Smooth hover effects and animations
Built with pure HTML, CSS, and JavaScript
🛠️ Technologies Used
HTML5
CSS3
JavaScript (Vanilla JS)
